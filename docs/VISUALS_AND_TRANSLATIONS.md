# 화면 리소스와 한국어 재료명

- `app/static/photos/`: Pexels 요리 참고 사진 30장. `credits.json`에 원본 주소와 이용 조건 기록
- `app/static/photo-credits.html`: 사용자가 열어볼 수 있는 사진 출처 페이지
- `app/static/visuals.js`: 메뉴 이름 우선, 재료 이름 보조로 사진 선택. 해당 레시피를 직접 촬영한 사진이 아니므로 참고 사진 표시 유지
- 사진 요청 실패 시 `hero-bowl.svg`로 대체
- 재료별 이모지가 없는 경우 재료명이 붙은 SVG 보관 병 표시
- 냉장고는 12개 초과 재료도 스크롤하여 확인 가능
- `app/static/hero-bowl.svg`: 프로젝트에서 직접 작성한 채소·달걀 볼 SVG

## 한국어 표시

`app/ingredient_ko.json`과 `app/localization.py`에서 한국어 표시와 검색 별칭을 관리한다. 모델 입력에는 기존 영문 ID를 그대로 사용한다. 사진이나 번역으로 추천 점수는 바뀌지 않는다.

약 12,547개 실제 재료 ID 중 약 6,800개는 영문 없이 표시된다. 전체 레시피의 재료 등장 횟수 기준 약 96%를 커버한다. 자주 쓰는 이름은 직접 대응하고, 나머지는 긴 재료 구문과 조리 상태 표현을 조합한다. 이는 번역 정확도 점수가 아니며 일부 생소한 상품명과 문구에는 원문이 남는다. 검색 결과에 원문을 함께 표시하여 구별한다.

사진 매칭과 조합 번역은 휴리스틱이다. 정확한 메뉴 사진이나 개별 상품 번역을 확보하면 해당 규칙보다 우선하는 대응표로 보완한다.
